DNS helps distribute traffic by returning different IP addresses for replicated servers, allowing users to be routed to different servers and balancing the load across them.

Here's the simple DNS hierarchy flow:
Local DNS -> Root DNS → TLD DNS (.com, .org, .edu) → Authoritative DNS → Final IP address of the website.
Example for www.amazon.com:
Root DNS: "Ask a .com DNS server."
.com TLD DNS: "Ask Amazon's authoritative DNS server."
Amazon authoritative DNS: "www.amazon.com = 54.x.x.x"

HTTP/3 uses QUIC over UDP instead of TCP, providing reliable, encrypted communication with independent streams.
Because streams are independent, packet loss in one stream does not block other streams, making web pages load faster and reducing latency on unreliable networks.
